Score a sign-up in your browser

signup-guard checks the email and the IP address of a sign-up for throwaway inboxes, datacenter, Tor and relay addresses and too many attempts, and answers allow, review or block with the reasons behind it. This page runs the JavaScript library on the data snapshot of the package. Nothing you type leaves the tab.

Try it

Pick an example or type your own. The page loads the data snapshot once and scores everything here: pressing the button makes no request, and the email and the IP address stay in this tab.

Each press records one attempt, as a sign-up form would. Press the button a few times with the same input to trip a limit. The counters live in this tab.

The data snapshot loads when you get here.

    Reasons and points
    
      
    The score is the sum of the points of the reasons. Nothing else goes into it. Below {{REVIEW}} the decision is allow, from {{REVIEW}} it is review, from {{BLOCK}} it is block. A reason with 0 points still appears, as information for your logs.
    
    
    
    
    
      
            {{REASONS}}
        
    
        
    CodePointsAdded whenHint shown to the user
    
        
      
    
    
    
    
    These are the defaults, and weights and thresholds are options. No network signal blocks on its own: a block needs either a bad email or several signals together. The hint never names a limit or a list, so it is safe to show to the person signing up.
    
  
    

  
    
    
    
      
    Use it in your sign-up form
    
      
    Call it on the server when the form is submitted, with the client IP your own proxy reports. The JavaScript and the PHP port take the same input, share one set of test vectors and give the same answer.
